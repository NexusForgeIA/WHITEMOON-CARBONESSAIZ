# WHITEMOON-CARBONESSAIZ

Demo comercial de WhiteMoon Agencia IA para **Carbones Saiz** (leña y carbón, Collado Villalba).
Clon de la demo WHITEMOON-PLAGAS-CONTROL con los datos reales de carbonessaiz.com.

- HTML/CSS/JS puro, una sola página (`index.html`).
- Fuentes autoalojadas (`fonts/`, Anton y Inter, licencia SIL OFL). Sin Google Fonts.
- Fotos y logo en `img/`, tomados de carbonessaiz.com (material del propio cliente, solo para la demo).
- Chatbot guiado sin backend: prepara el pedido y lo abre en WhatsApp (660 15 25 85). No guarda datos.
- `noindex,nofollow`: es una demo y repite contenido de la web real del cliente.
